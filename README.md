# 🦊 Geometric Shapes Detection with YOLOv8 (FInal ver)

Проект для определения геометрических фигур с использованием YOLOv8. 

## 📁 Структура проекта
project/

├── dataset/ # Исходный датасет

      │  ├── test/ # Тестовые данные

      │  ├── train/ # Данные для обучения

      │  ├── val/ # Данные для валидации

      │  └── dataset.yaml # Конфигурация датасета

├── ConvertDatasetToYOLO.py # Конвертер разметки в формат YOLO

├── ViewResultYOLO.py # Скрипт обучения модели

├── testYOLOBestModel.py # Тестирование обученной модели

├── MetricsView.py # Анализ метрик модели

└── runs/ # Результаты обучения

      └── detect/

            └── geometric_shapes/

               └── weights/


## 🚀 Последовательность работы

1. **Подготовка данных**
   - Исходный датасет находится в папке `dataset/`
   - Содержит размеченные изображения и JSON файлы
   - Скрипт `ConvertDatasetToYOLO.py` уже выполнил конвертацию в формат YOLO
   > ⚠️ Повторный запуск конвертера не требуется

2. **Обучение модели (ViewResultYOLO.py)**
   - Использует предобученную модель YOLOv8n
   - Классы определяются из `dataset/dataset.yaml`
   - Результаты сохраняются в `runs/detect/geometric_shapes/`

3. **Тестирование (testYOLOBestModel.py)**
   - Использует изображения из `dataset/test/`
   - Применяет обученную модель `best.pt`
   - Результаты сохраняются в:
     * `test_result/` - размеченные изображения
     * `test_result_graph/` - графики метрик

4. **Анализ метрик (MetricsView.py)**
   - Альтернативный просмотр метрик модели
   - Показывает:
     * Обобщенные метрики модели
     * Метрики по каждому классу
   > 📝 Рекомендуется использовать вместо метрик из ViewResultYOLO.py

## 📊 Основные метрики


- **mAP50**: Точность определения при 50% перекрытии
- **mAP50-95**: Усредненная точность при разных порогах
- **Box Loss**: Ошибка определения положения объектов
- **Class Loss**: Ошибка классификации
- **DFL Loss**: Ошибка распределения границ
- **Accuracy**: Точность классификации (доля правильных определений)
- **F1-score**: Гармоническое среднее между точностью и полнотой
  * Сбалансированная метрика качества модели
  * F1 = 2 * (precision * recall) / (precision + recall)

### Метрики обучения:

- **Box Loss**: Ошибка определения положения объектов
- **Class Loss**: Ошибка классификации
- **DFL Loss**: Ошибка распределения границ

### Интерпретация:

- **Accuracy** показывает % правильно определенных фигур
- **F1-score** учитывает баланс между:
  * Precision (точность) - сколько из определенных фигур действительно правильные
  * Recall (полнота) - сколько фигур было найдено из всех имеющихся

## 🛠 Использование


1. Клонируйте репозиторий
2. Убедитесь в наличии всех зависимостей:

```bash
pip install ultralytics opencv-python numpy matplotlib seaborn
```
3. Запустите тестирование:

```bash
python testYOLOBestModel.py
```

4. Запустите анализ метрик:

```bash
python MetricsView.py
```
